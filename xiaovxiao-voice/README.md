# 哓v哓 · 找音色工具包

目标：在没有任何参考音频的情况下，用「文字描述造声」批量生成候选，一轮轮筛选，
最后得到一段 **哓v哓_定妆音.wav**。以后所有配音都拿它当参考音频，声音就固定下来了。

```
校准 r0 ──► 模型对比 r0b ──► step1 海选 ──► 试音台粗选 ──► step2 精调 ──► step3 克隆测试 ──► step4 定妆
 已完成       24条，三个模型     约60条          打分+标签       约90条          每个候选7句         定妆音.wav
```

| 文件 | 作用 |
|---|---|
| `DEPLOY.md` | 部署说明，交给帮你部署的 AI 照着做 |
| `specs.py` | 哓v哓 的声音设定：试音台词、描述槽位、10 个海选方向。想改方向就改这里 |
| `step1_audition.py` | 海选：批量生成候选 |
| `rater.html` | 试音台：双击用浏览器打开，盲听打分 |
| `step2_refine.py` | 精调：围绕高分候选做单变量微调 |
| `step3_clone_test.py` | 克隆测试：检验候选当参考音频时稳不稳 |
| `step4_finalize.py` | 定妆：导出最终参考音频和声音档案 |
| `measure.py` | 声学测量：音高、语调起伏、停顿、语速、气声。每轮生成完自动运行 |
| `dub.py` + `dub/` | 给视频配音：按字幕时间逐句落位、混音、合成视频（见第 7 节） |
| `voices/` | 定下来的音色版本，目前是 [v1](voices/README.md) |

## 0. 部署

把 `DEPLOY.md` 交给帮你部署的 AI。它会给每个模型跑一条 `--smoke` 验收命令，各生成 1 条音频，能播放就说明好了。

本机部署和试听样本：[2026-10-21 Windows 部署报告](reports/2026-10-21-windows-deployment/README.md)。当前进度与同步约定见 [PROGRESS.md](PROGRESS.md)。

下面的命令都在本文件夹里运行。三个模型各有一个环境：`xvx-vox`（VoxCPM2）、`xvx-qwen`（Qwen3-TTS）、`xvx-moss`（MOSS-VoiceGenerator）。

## 1. 校准 r0（已完成）

用 v2 设定的 4 个方向，比较了 VoxCPM2 的 cfg 1.5/2.0 × 步数 10/20 和 Qwen3 的温度 0.9/1.0，共 24 条。
结果见 [r0 报告](reports/2026-10-22-calibration-r0/ratings-analysis.md)：

- **生成参数不是关键**：各组平均分都在 2.25～2.75 之间，差距来自个别样本。以后固定用 VoxCPM2 `cfg 2 / 步数 10`（也是默认值，最快）、Qwen3 `温度 0.9`。
- **人机感 23/24 条**，不管什么参数都有 → 问题在模型和描述本身，所以下一步加入主打「真人感」的 MOSS-VoiceGenerator 做对比。
- 不够可爱 17、播音腔 11、不够忧郁 11、太成熟 9、杂音/电音 9、慵懒过重 6；还有「台湾腔」的感觉。
- 你的备注：忧郁做底色，带一点可爱，尾音带一点傲娇、害羞。

据此改成了 **v3 设定**（`specs.py`）：
- 新增「可爱程度」和「尾音（害羞 / 小傲娇）」两个槽位；
- 去掉偏成熟的温润、学姐、疏离方向，去掉「稍慢」；
- 描述末尾只用正面说法：「普通话标准，像普通女生私下跟朋友随口说话，真实自然」，不再出现「播音」「夹」这类词；
- 试音台词结尾加了一句害羞的小傲娇，方便听尾音。

## 1b. 模型对比 r0b

同样的 v3 描述，三个模型各生成 8 条（4 个方向 × 2 个种子），一共 24 条，比哪个模型最不像机器：

```bat
conda activate xvx-vox
python step1_audition.py --model voxcpm2 --only A,B,C,E --langs zh --seeds 2 --out rounds\r0b

conda activate xvx-qwen
python step1_audition.py --model qwen3 --only A,B,C,E --langs zh --seeds 2 --temperature 0.9 --out rounds\r0b

conda activate xvx-moss
python step1_audition.py --model moss --only A,B,C,E --langs zh --seeds 2 --out rounds\r0b
```

盲听打分后看统计里的「模型」那一栏。海选只用得分最高的一两个模型，省时间。

**关于 MOSS-VoiceGenerator**：OpenMOSS 团队 2026 年开源，1.7B，Apache-2.0。它的训练数据来自影视剧台词，官方主打「像真人说话、带自然的换气和停顿」，
自测在偏好度、指令遵循、自然度上都赢过 Qwen3 VoiceDesign 等模型（团队自己的评测，还要靠你的耳朵验证）。它只能造声，不能做第 5 步的克隆测试。

## 2. 海选

用 r0b 里得分最高的模型（下面以 MOSS 为例）：

```bat
conda activate xvx-moss
python step1_audition.py --model moss
```

- 输出到 `rounds\r1`，默认是 10 个方向 × 中/英文描述 × 3 个种子 = 60 条。两个模型都要就各跑一次，共 120 条。
- 生成参数用默认值就行（VoxCPM2 cfg 2 / 步数 10；Qwen3 加 `--temperature 0.9`；MOSS 用官方推荐值）。
- 按部署报告里的实测速度，VoxCPM2 约 35 秒一条、Qwen3 约 65 秒一条；MOSS 的速度以第一次运行打印的为准。
- 想先看看描述长什么样：加 `--dry-run`。
- 随时可以 Ctrl+C 中断，重新运行同一条命令会接着生成，已生成的不会重复。
- 嫌多就缩小范围，例如 `--seeds 2`、`--langs zh`、`--only A,B,C`。

**10 个方向**（v3 设定，都以忧郁为底色、带一点可爱，详细描述见 `specs.py`）：
A 忧郁小甜 · B 害羞心事 · C 小傲娇 · D 软糯低落（16 岁）· E 寂寞小猫 · F 清亮忧郁 · G 甜而不腻（16 岁）· H 安静可爱（19-20 岁）· I 傲娇心事（19-20 岁）· J 一丝慵懒

参数校准的用法还保留着：`--cfg`、`--steps`、`--temperature` 都可以写多个值（逗号分隔），一次生成所有组合来对比。

## 3. 粗选（试音台）

1. 双击 `rater.html`，用 **Edge 或 Chrome** 打开。
2. 点「打开文件夹（自动保存）」，选 `rounds\r1`，允许读写。评分会自动保存成这个文件夹里的 `ratings.json`。
   （用「选择文件夹」的话，评完要点「导出评分」，再把下载的 `ratings.json` 放进 `rounds\r1`。）
3. 切到英文输入法开始听。默认 **盲听**：只显示编号，看不到是哪个方向、哪个模型，避免先入为主。

**打分标准**

| 分 | 含义 |
|---|---|
| 5 | 就是她！像真人配音 |
| 4 | 很接近，值得精调 |
| 3 | 有可取之处 |
| 2 | 方向偏了 |
| 1 | 完全不对，或有明显瑕疵 |

**第一道关是「像不像真人」**：一听就有人机感的，音色再喜欢也最多 3 分，并标「人机感」（`D`）。
慵懒要「细听才听得出来」，一听就很明显的标「慵懒过重」（`F`）。

**快捷键**：`空格` 播放/暂停 · `1`–`5` 打分 · `←` `→` 切换 · `N` 下一条未评 · `R` 重播 ·
`C` 放进对比槽 / `B` 播放对比槽（A/B 对比）· 字母键贴标签（`Q` 太成熟、`W` 太幼、`E` 太尖、`A` 太闷、
`S` 夹/做作、`D` 人机感、`F` 慵懒过重、`Z` 不够忧郁、`X` 不够可爱、`T` 播音腔、`Y` 杂音/电音、`V` 口音不对、
`K` ✓像真人、`G` ✓喜欢音色、`H` ✓质感好、`J` ✓情绪对）。
先贴标签再打分，打完分会自动跳到下一条。

读错字、某个停顿怪，这一轮先不扣分。每听 20 条左右休息一下。
听完一遍后把筛选切到「4 分以上」，再复听一遍确认。

评完点「显示统计」，可以看到：哪个方向、哪组生成参数、中文还是英文描述、哪个模型、每个槽位（年龄感、音调、可爱程度、尾音……）的哪个选项平均分最高。

**声学数字**：关掉盲听后，每条下面会显示「音高、起伏、停顿、语速、谐噪比」，最高分列表里也有。可以这样看：

| 数字 | 意思 | 第一次试听的两条 |
|---|---|---|
| 音高 Hz | 越高越显小 | 231 / 253 |
| 起伏（半音） | 语调起伏的幅度，太小就是「平」，人机感常见来源 | 6.1 / 3.6（Qwen 那条很平） |
| 停顿 % | 说话过程中停顿占的比例 | 32% / 34%（r0 的 24 条都在 27%～42%，超过 40% 才提示） |
| 语速 字/秒 | 不算停顿的语速 | 5.1 / 4.1 |
| 谐噪比 dB | 越低气声越重 | 12.4 / 14.3 |

数字只帮你理解「为什么听着不对」，最终以耳朵为准。

## 4. 精调

在你更喜欢的那个模型的环境里运行（两个都喜欢就各跑一次）：

```bat
conda activate xvx-vox
python step2_refine.py --model voxcpm2
```

它会自动取 `rounds\r1` 里该模型分数最高的 3 条（≥4 分），生成到 `rounds\r2`：

1. **原描述换 4 个新种子**：分清是「这个方向好」，还是「这一条运气好」。
2. **单变量微调**：年龄感、音调、质感、可爱程度、尾音、慵懒程度，每次只改一项，其它都不动（`--axes all` 连鼻音、语速、情绪底色也试）。
3. **统计最优组合**：把每个槽位平均分最高的选项拼成一条新描述。
4. **精调起点**：上一轮的原条也会复制进来。盲听时它是对照组；关掉盲听后，可以把它放进对比槽（`C`），和变体来回比（`B`）。

生成参数（cfg、步数、温度）默认沿用每条候选自己当时的参数，也可以在命令里重新指定。
默认每个模型约 90 条，按实测速度 VoxCPM2 大约 1 小时；想快一半就加 `--seeds 1`。

运行时会根据你贴的标签给提示，比如标了「太成熟」，会提醒你重点听「年龄感 → 更小」的那几条；标了「慵懒过重」，会提醒你听「慵懒程度」变轻的那几条。

然后用试音台打开 `rounds\r2` 再评一轮。还想继续往下细调：

```bat
rem 把 r1、r2 的评分合起来，再精调一轮
python step2_refine.py --model voxcpm2 --from rounds\r1 rounds\r2 --out rounds\r3

rem 只围绕某一条，所有槽位都试
python step2_refine.py --model voxcpm2 --ids r2_vox_1a2b3c --axes all

rem 自己手写描述
python step2_refine.py --model voxcpm2 --custom "二十岁左右的女生，声音柔和，……"
```

候选的 id 在试音台关掉盲听后就能看到，统计里的「最高分 15 条」表也列着。

## 5. 克隆测试

海选和精调都只听了同一句台词，而以后真正配音靠的是「克隆」。这一步把最终候选当成参考音频，
让模型用这个声音说 7 句完全不同的话：日常、忧郁、可爱、傲娇、疑问、长句、中英混。

```bat
conda activate xvx-vox
python step3_clone_test.py --model voxcpm2
```

默认取 `rounds\r1`、`rounds\r2` 里分数最高的 4 条，输出到 `rounds\clone`，参考原声也会复制进去方便对照。
用试音台打开时 **建议关掉盲听**，按「参考原声」分组看平均分。重点听三件事：

- 7 句听起来是不是 **同一个人**；
- 「忧郁」和「可爱」两句有没有演出来；
- 长句、中英混读有没有崩。

（`--model qwen3` 用 Qwen3 的 Base 模型克隆，它不支持语气控制。）

## 6. 定妆

选出最终那一条（**从海选或精调里选原条，不是克隆出来的那条**），导出：

```bat
python step4_finalize.py rounds\r2\r2_vox_1a2b3c.wav
```

会在 `final\` 里生成：

- `哓v哓_定妆音.wav`：去掉首尾静音、统一了音量
- `哓v哓_定妆音.txt`：这段音频对应的文字
- `哓v哓_声音档案.json`：它的描述、模型、种子，以后想追溯或重现都靠它

**把 `final` 文件夹备份好。** 以后配音时：

- VoxCPM2：`reference_wav_path` 填定妆音；要更像就同时填 `prompt_wav_path`（同一个文件）和 `prompt_text`（txt 里的文字）。
- IndexTTS-2.5：WebUI 的「音色参考音频」放定妆音。

## 7. 给视频配音（晓念 V10）

用定下来的音色给比赛视频配旁白。只用 VoxCPM2（`xvx-vox` 环境）：克隆音色，再用一句话控制每一段的语气。
配音稿已整理成 `dub/xiaonian_v10.json`：55 句、每句的字幕时间、24 个生成组、每组的语气。
发音替换只用在合成输入里：`SQLite → S Q light`、`明了 → 明瞭`。字幕和正式文稿不受影响。

**第一步 · 试配选音色**（4 个候选 × 4 段 = 16 条，约 5 分钟）：

```bat
python dub.py test --refs r0b_vox_821713,r0b_vox_49a14f,r0b_moss_611767,r0_vox_959950
```

用试音台盲听 `dub\out\test`。这次的标准是「适不适合正式解说」：清楚、自然、有交流感，不是角色感。
评完看统计里的「方向」，那一栏就是各个音色的平均分。

**第二步 · 正式配音**：

```bat
python dub.py render --ref r0b_vox_821713 --video 成片.mp4
```

它会做这些事：
1. 每组生成 3 条备选（同组几句一起生成，保住上下文）；
2. 用语音识别核对有没有漏读、错读（第一次会从 ModelScope 下载识别模型，可用 `--no-asr` 跳过）；
3. 每组挑一条最合适的：识别差异小，又放得进字幕时间；
4. 按静音把整组切回一句一句，每句从它的字幕时间开始。放不下就整组统一加速，最多 1.1 倍，过长的停顿会先缩短；
5. 混音：说话时底乐压低 8 dB，没人说话时自然抬回来，整体响度 -16 LUFS；
6. 合成视频：画面原样复制，只换音轨，自动控制在 30MB 以内。

输出在 `dub\out\<音色>_style\final\`：
- `晓念V10_配音版.mp4`：成片
- `人声轨_48k24bit.wav`：178 秒纯人声，和视频从 00:00 对齐
- `segments\A.wav`～`H.wav`：按稿子分的八段人声
- `mix.wav`：混好的音轨
- `配音报告.md`：逐句的字幕时间、实际时间、加速倍数、用的哪一条，以及需要注意的地方

有 BGM 和音效分轨时，加 `--music music.wav --sfx sfx.wav`，效果比直接用视频原音轨好。

**第三步 · 改**：
- 某组不满意：用试音台打开 `dub\out\<音色>_style\takes`，在同组里给你想要的那条打最高分，然后运行
  `python dub.py assemble --ref r0b_vox_821713 --video 成片.mp4`，不用重新生成。
- 三条都不行：`python dub.py render --ref r0b_vox_821713 --only 05-06,14 --takes 6 --video 成片.mp4`，给这几组多生成几条。
- 可调的混音参数：`--duck-db`（底乐压低多少）、`--voice-over-bed`（人声比底乐响多少）、`--lufs`（整体响度）。

## 常见问题

**台词里的名字为什么写成「晓晓」？**
哓v哓 读 xiǎo xiǎo（三声），v 不读出来。「哓」是生僻字，模型会按字典读成一声，所以台词里写同音的「晓晓」。想换的话改 `specs.py` 的 `NAME_SPOKEN`。

**换了参数和描述还是有人机感？**
「文字描述造声」本身有上限，凭空造出来的声音通常不如克隆真人录音自然。三个办法，按顺序试：
1. 把听着最自然的那条拿去做第 5 步克隆测试：克隆出来的声音往往比造声更自然。
2. 精调时加 `--axes all`，连情绪底色和说话方式一起试；或者用 `--custom` 写更口语化的描述。
3. 还是不行的话，最有效的是用一段真人录音（你自己，或者愿意授权的朋友）做底子，再往哓v哓的方向调。

**描述的效果不明显，听起来都差不多？**
VoxCPM2 可以加大引导强度，比如 `--cfg 2.5`，让声音更贴近描述（但太高可能更僵）。也可以对比统计里的中文/英文描述，哪种更有效就只用哪种（`--langs en`）。

**太慢了？**
少生成一些（`--seeds 2`、`--langs zh`、`--only ...`）。VoxCPM2 的步数越少越快、细节越差。
每条的用时和剩余时间，运行时都会打印出来。

**显存不够？**
同一时间只跑一个模型，关掉游戏和其它占显存的程序。

**step2 / step3 说没有评分？**
`ratings.json` 必须放在那一轮自己的文件夹里（比如 `rounds\r1\ratings.json`）。用「打开文件夹」评的会自动保存进去；用「选择文件夹」评的，要手动导出再放进去。

**想换方向、改台词？**
都在 `specs.py` 里：`AUDITION_LINE` 是试音台词，`SLOTS` 是描述用的词，`ARCHETYPES` 是 10 个海选方向。改完重新跑 step1，可以用 `--out rounds\r1b` 另开一轮。
